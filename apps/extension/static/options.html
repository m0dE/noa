Helper

    1. Install Claude Code and sign in to it once.
    2. Open Terminal: press ⌘ Space, type Terminal, press Return.
    3. Click Copy, paste it into Terminal (⌘ V) and press Return. It takes about a minute and ends with “Done”.
    4. From a copy of the Noa repository, run pnpm install, pnpm build, then node apps/helper/dist/install.js.
    5. Come back to this page. It connects by itself; if not, click Connect.
